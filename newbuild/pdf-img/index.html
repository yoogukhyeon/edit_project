PDF 이미지 변환이 필요한 경우

PDF 이미지 변환 도구는 PDF 문서를 이미지 파일로 바꿔 공유하거나 보관하고 싶을 때 사용할 수 있는 무료 변환 도구입니다.

문서 페이지를 이미지로 저장합니다

PDF 안의 각 페이지를 이미지로 변환해 압축 파일로 내려받을 수 있습니다. 문서 내용을 이미지 게시물, 썸네일, 자료 화면으로 활용할 때 편리합니다.

브라우저에서 바로 변환합니다

별도의 PDF 변환 프로그램을 설치하지 않아도 파일을 선택해 변환을 시작할 수 있습니다. 큰 파일은 변환 시간이 길어질 수 있으니 5MB 이하 파일 사용을 권장합니다.

자주 묻는 질문

PDF를 JPG로 변환할 수 있나요?

PDF 페이지를 이미지로 변환한 뒤 ZIP 파일로 내려받을 수 있습니다.

여러 페이지 PDF도 변환되나요?

네. PDF의 각 페이지를 순서대로 이미지로 변환합니다.

PDF 이미지 변환이 안 될 때는 어떻게 하나요?

파일 용량과 PDF 파일 형식을 확인하고, 브라우저를 새로고침한 뒤 다시 시도해 보세요.
