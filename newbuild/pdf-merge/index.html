PDF 합치기

PDF 파일을 추가하고 순서를 정한 뒤 합치기를 누르세요. 파일은 브라우저 안에서만 처리됩니다.

EVERYDAY 웹툴/PDF/PDF 합치기

PDF 합치기 사용법

PDF 합치기는 여러 개의 PDF 파일을 원하는 순서대로 하나의 PDF로 병합하는 무료 도구입니다. 프로그램 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

흩어진 서류를 하나의 파일로 제출합니다

입사 지원 서류, 증빙 자료, 계약서처럼 여러 PDF를 한 파일로 제출해야 할 때 유용합니다. 파일을 추가한 뒤 위아래 버튼으로 순서를 정하고 합치기를 누르면 merged.pdf 파일이 내려받아집니다.

파일이 외부로 전송되지 않습니다

PDF 병합은 브라우저 안에서 처리되어 서버에 파일이 업로드되지 않습니다. 개인정보가 담긴 서류도 안심하고 합칠 수 있습니다.

원본 품질 그대로 합칩니다

페이지를 이미지로 바꾸지 않고 PDF 구조 그대로 복사하므로 글자 선택, 검색, 화질이 원본과 동일하게 유지됩니다.

자주 묻는 질문

몇 개까지 합칠 수 있나요?

한 번에 최대 20개의 PDF를 합칠 수 있습니다. 파일이 매우 크면 기기 성능에 따라 시간이 걸릴 수 있습니다.

암호가 걸린 PDF도 합칠 수 있나요?

암호로 보호된 PDF는 읽을 수 없어 합칠 수 없습니다. 암호를 해제한 뒤 다시 시도해주세요.

특정 페이지만 골라서 합치고 싶어요.

PDF 나누기 도구에서 필요한 페이지만 추출한 뒤, 추출한 파일들을 PDF 합치기로 병합하면 됩니다.
